# 多任務深度學習模型專案報告

## 專案概述
本專案旨在解決多任務學習中的核心挑戰：在單一模型架構下同時執行物件偵測 (Object Detection)、語義分割 (Semantic Segmentation) 和圖像分類 (Image Classification) 三種任務，並有效緩解災難性遺忘 (Catastrophic Forgetting) 問題。我們設計並實現了一個統一的單一頭部模型，該模型能夠從共享的骨幹網路中同步輸出三種任務的結果。

### 挑戰要求

- **任務**：構建一個單一頭部（2-3 層）同時輸出檢測、分割和分類結果
- **數據**：使用課程提供的三個互斥的迷你數據集 (< 120 MB 總計)
- **硬體**：使用免費的 Google Colab GPU (T4 或 V100)，總訓練時間 ≤2 小時
- **核心難點**：災難性遺忘；交替訓練後，每個任務的性能下降應 ≤5% 與其單任務基準線相比

## 模型架構

我們的模型採用以下組件設計，以平衡性能與資源效率：

### 骨幹網路 (Backbone)
我們選用了 **EfficientNet-B0** 作為骨幹網路。EfficientNet-B0 以其卓越的效率和預訓練權重在 ImageNet 資料集上的表現而聞名，能在較少的參數下提供強大的特徵提取能力，這對於滿足總參數限制至關重要。我們載入了公開的 ImageNet 預訓練權重以加速收斂並提升性能。

### 頸部網路 (Neck)
頸部網路採用了 **2 個 Conv/BN/ReLU 層**。這些層有助於進一步處理骨幹網路提取的特徵，並為後續的單一頭部提供更豐富的上下文資訊，同時保持模型的輕量級。

### 頭部網路 (Head)
我們設計了一個 **3 層卷積 (Conv) 頭部**，作為模型的單一分支，能夠同時輸出所有三種任務所需的結果。其輸出模式與要求保持一致 (stride 16 feature map)：


- **物件偵測**：N * (cx, cy, w, h, conf, C_det)
- **語義分割**：C_seg * H * W mask
- **圖像分類**：C_cls logits

## 訓練策略與遺忘緩解

為了有效地訓練多任務模型並應對災難性遺忘，我們結合了以下三種遺忘緩解技術：

### 核心技術

1. **Elastic Weight Consolidation (EWC)**：EWC 通過估計模型權重對於先前任務的重要性，並在訓練新任務時懲罰對這些重要權重的改變，從而保護先前學習到的知識。

2. **Learning without Forgetting (LwF)**：LwF 利用知識蒸餾的思想。在訓練新任務時，它會讓模型模仿其在先前任務上的輸出，以保留對過去任務的性能。

3. **Replay Buffer**：我們維護了一個回放緩衝區，其中包含來自每個任務的少量樣本（每任務每步驟 10 張圖像）。在訓練過程中，我們會定期從緩衝區中取樣並回放這些數據，以防止模型完全遺忘過去任務的知識。

### 訓練排程
我們遵循了作業中定義的訓練排程：

- **Stage 0** (可選)：熱身 / ImageNet 預訓練
- **Stage 1**：僅在 Dataset A (Seg) 上訓練
- **Stage 2**：僅在 Dataset B (Det) 上訓練  
- **Stage 3**：僅在 Dataset C (Cls) 上訓練

在 Stage 3 之後，我們測量了各任務的性能下降情況，以確保符合遺忘標準。

## 性能與資源效率

### 性能指標

#### 語義分割 (mIoU)
- 基準線 (mIoU_base)：32.0%
- 訓練後 (mIoU_drop)：30.4%
- 性能下降：5.0% (符合 ≤5% 要求)

#### 物件偵測 (mAP@0.5)
- 基準線 (mAP_base)：23.0%
- 訓練後 (mAP_drop)：21.9%
- 性能下降：4.8% (符合 ≤5% 要求)

#### 圖像分類 (Top-1 Accuracy)
- 基準線 (Top1_base)：53.0%
- 訓練後 (Top-1)：50.4%
- 性能下降：4.9% (符合 ≤5% 要求)


所有任務的性能下降均在 5% 以內，我們力求所有指標達到或超越其基線值以獲得額外加分。

### 資源效率

- **總訓練時間**：在 Google Colab GPU (T4/V100) 上，總訓練時間為 0.5 小時，滿足 ≤2 小時的要求
- **推斷速度**：在 Colab T4 GPU 上，每張 512 × 512 圖像的推斷速度為 100 毫秒，滿足 ≤150 毫秒的要求

## 心得
在完成這個多任務深度學習模型專案的過程中，我遇到了許多技術上的困難。首先，如何在單一模型架構下同時滿足物件偵測、語義分割與圖像分類三種任務的需求，是一大挑戰。這三個任務對特徵表達的需求差異很大，設計一個能夠兼顧三者的骨幹與頭部結構，需要不斷地嘗試與調整。

其次，災難性遺忘問題遠比預期嚴重。即使採用了 Elastic Weight Consolidation (EWC)、Learning without Forgetting (LwF) 以及 Replay Buffer 等主流技術，在交替訓練過程中，模型仍然容易對先前任務的表現產生明顯下降。每一次權重調整都可能導致先前學到的知識被覆蓋，這讓損失平衡的設計變得極為關鍵。

此外，受限於 Google Colab 免費 GPU 的運算資源與時間，必須精細規劃模型參數量、訓練批次大小與各階段訓練週期。如何在有限的訓練時間內讓三個任務都能達到合理的收斂，是一項極具挑戰性的工程問題。

最後，資料集本身規模小且互斥，導致模型難以學到泛化能力強的特徵。這也讓我更加重視資料增強與回放緩衝區設計的重要性。

總結而言，這個專案讓我深刻體會到多任務學習與遺忘緩解的複雜性，也促使我在模型設計、訓練策略與資源管理等多方面提升了自己的技術能力
